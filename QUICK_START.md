## 📊 Understanding Your Stats

### Points
- **Total**: All-time earnings
- **Today**: Reset at midnight
- **Sources**: Tasks (15-30) + Timer (2/min)

### Streak
- **Count**: Consecutive active days
- **Requirement**: Complete at least 1 task daily
- **Bonus**: Increases focus score

### Level
- **XP Needed**: 100 points per level
- **Progress**: Visual bar shows current XP
- **Benefits**: Higher levels = better focus score

### Focus Score
- **Formula**: Completion rate (50%) + Streak bonus (5 per day, max 30) + Level bonus (10 per level)
- **Range**: 0-100
- **Use**: Measure overall productivity health

## ⚙️ Customization

### Sound Preferences
Sounds are enabled by default. To disable:
1. Open browser console (F12)
2. Type: `dm.data.preferences.soundEnabled = false`
3. Type: `dm.save()`

### Default Timer
Change default timer duration:
1. Open browser console (F12)
2. Type: `dm.data.preferences.defaultTimer = 45` (or any number)
3. Type: `dm.save()`

### Reset All Data
Start fresh (WARNING: deletes everything):
1. Open browser console (F12)
2. Type: `localStorage.clear()`
3. Reload page (F5)

## 🐛 Troubleshooting

### Issue: Particles not showing
**Solution**: Refresh page (F5) or check browser console for errors

### Issue: Chart not updating
**Solution**: Complete a task to trigger update, or refresh page

### Issue: Sounds not playing
**Solution**: Click anywhere on page first (browser autoplay policy), then try again

### Issue: Data disappeared
**Solution**: Check if localStorage is enabled in browser settings

### Issue: Timer stuck
**Solution**: Click "Reset" button, then start again
